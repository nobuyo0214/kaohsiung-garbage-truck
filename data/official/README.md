# 官方證據快照

`sanmin-west.csv` 是 2026-10-20 查閱環境部三民西區1、4、6路線頁面所見的轉錄，共 179 筆。逐列保留實際頁面網址與清運序；一般垃圾欄位與資源回收欄位分開，未使用回收日推算。

- 路線1：48 筆；路線4：69 筆；路線6：62 筆。
- 官方名稱的數字表示路線，不代表 CSV 車次；車次留白。
- 責任區與來源檔案關係沿用既有對照規則所引用的官方路線，僅供找出待人工查證的候選。
- 官方時間是到點時間，未補造離站時間。
- 路線6第二頁的 12 筆只取得搜尋服務約 1.4 年前快取，`證據狀態=stale`，工具禁止產生新增候選；其他頁面同樣不保證等於即時官方版本。
- 查閱日期不是官方更新日期。此檔不直接載入搜尋頁，也不代表完成重新核實。

後續請重新取得官方原始版本，確認車次、完整時間與一般垃圾日期，再以相同表頭重跑比對。不要直接補入推測的車次或 CSV 結束時間。
