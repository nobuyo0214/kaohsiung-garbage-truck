# 民眾便利功能：分享、導航、收藏備份與主畫面

這次延續 PR #6 的綠色與暖白色首頁，民眾卡片只顯示停靠地點、表定時間及資源回收日，不變更原始站點或歷史日期資料。38區、39份原始CSV、13,871筆有效來源紀錄與243條一般垃圾日期規則完整保留。

## 停靠站地圖導航

搜尋後，通過位置品質檢查的卡片會出現「地圖導航」。按下後使用[Google Maps官方跨平台導航網址](https://developers.google.com/maps/documentation/urls/get-started)：手機依裝置及安裝狀況開啟 App 或瀏覽器，電腦開啟網頁。不需要API金鑰或付費服務。

目的地只取原CSV的經緯度，不做地理編碼，不補座標，不自動交換經緯度。「位置尚待確認」表示暫不提供導航；電腦游標停留可看原因，全部原因也保留於品質報告。不提供導航不影響查詢、收藏或複製。

位置尚待確認但地點文字足夠明確時，卡片改提供「在 Google Maps 搜尋地點」，並顯示「搜尋結果不代表已核實的停靠位置」。它使用同一份[Google Maps官方網址說明](https://developers.google.com/maps/documentation/urls/get-started#search)的搜尋格式 `/maps/search/?api=1&query=…`，查詢內容只包含「高雄市＋行政區＋停靠地點」，沒有經緯度或導航參數。Google可能顯示一個地點或多個搜尋結果，都不是本站確認的停靠位置；請自行核對，並以主管機關公告為準。

空白、占位文字、純座標、只有「市場前」「轉彎處」等模糊描述、不在既有38區或過長的名稱，不提供搜尋按鈕。搜尋關鍵字須包含具名道路、門牌或具名公共地標等可辨識線索；這只是文字是否適合搜尋的保守判斷，不會核實位置。原有導航品質檢查、9,022筆可導航及4,849筆待確認的分類完全不變，也不儲存Google搜尋結果或自動修正資料。手機上維持兩個操作位置，顯示導航或搜尋其中一種，沒有增加審核介面。

品質條件包括：嚴格數字與世界經緯度範圍、至少4位小數、疑似軸向顛倒、高雄市與所屬行政區多邊形、原始行政區標示、同一識別／同區同地點的座標衝突，以及至少3個不同地點共用相同座標的可疑情況。不同車次同名地點有不同座標時保守保留待確認，不推測哪一個正確。

行政區範圍採[國土測繪中心開放資料集7441](https://data.gov.tw/dataset/7441)之[社群轉檔固定版本](https://github.com/jason2506/Taiwan.TopoJSON/blob/649946d37f84b1591fe353ddab74858dc8427aad/topojson/towns/towns-64000.json)，僅用於排除可疑座標。上游建置標示200公尺簡化，原圖資有效更新日期不明，因此距簡化區界不足300公尺也不提供導航。這不是最新官方區界的重新認證，更不是逐站現勘。取得日期、來源、授權與雜湊見 `data/geo/provenance.json`。

## 分享給家人朋友

按卡片「分享站點」。支援 Web Share 的瀏覽器會開啟系統分享；其他情況複製連結，剪貼簿被限制時提供手動選取的網址。取消系統分享不會再強迫開啟其他視窗。

接收者開啟連結後，載入當次版本資料，切換至該行政區，只顯示並醒目標記該站點；重新整理也保留定位。分享的是站點識別，不是清運日期快照。畫面上的資源回收日仍由當次原始路線CSV提供。歷史一般垃圾日期規則仍保留於專案，但不在民眾介面顯示。

連結使用 `#stop=1.…`，將來源檔案、行政區、責任區、車次、地點與完整時間做UTF-8安全編碼。它不使用易變流水號或畫面位置，也不包含私人收藏或搜尋歷史。行政區加上完整五欄用來避免混合來源誤配。

若站點改名、時間變更、識別缺項或原CSV有不唯一的識別，會提示「站點資料可能已變更」，不以同名或接近時間的站點替代。資料未完整取得時請先重試；離線時不會展示舊站點資訊。

## 收藏JSON備份與換手機

1. 開啟頁首或結果區的「我的收藏」。
2. 按「匯出收藏」，下載 `kaohsiung-garbage-favorites.json`。
3. 將檔案自行傳到另一台裝置，開啟同一網站的「我的收藏」。
4. 按「匯入收藏」選JSON，先看預覽：檔案識別數、新增數、合併後數量，以及目前無法唯一確認的數量。
5. 按「合併收藏」才儲存；按「取消」不修改原收藏。只提供合併去重，不提供直接取代。

JSON格式如下，實際值由匯出功能產生；下列為格式示意，不是新增的站點資料：

```json
{
  "format": "kaohsiung-garbage-truck/favorites",
  "version": 1,
  "favorites": [
    {
      "sourceFile": "sanmin-east.csv",
      "district": "三民區",
      "responsibility": "一",
      "trip": "1",
      "place": "鼎力路313號",
      "time": "16:52-16:53"
    }
  ]
}
```

備份沒有日期、座標、整份CSV、最近搜尋或其他瀏覽器資料。最大256KB，每檔最多200筆，合併後也最多200個不重複收藏；超過時整次停止，不截掉尾端。錯誤格式、版本、欄位或來源會顯示錯誤並保留原收藏。

資料已變更或不存在的完整識別仍保留，無法顯示時提示未載入／已變更，不會改配相似站點。舊介面可收藏的缺識別或原始時間異常紀錄仍可備份並標為待確認，不能因此成為可分享的完整識別。最近6次搜尋不納入搬移檔；舊的一般垃圾星期條件會提示已停用並清空星期，請重新選擇回收星期，不改配或刪除收藏。

收藏仍用原本 `garbage-search-v1` 的 localStorage 版本1，沒有強制遷移。禁止保存或空間不足時仍會提示；此時應自行下載備份，避免關閉頁面後遺失本次操作。

## 加入手機主畫面

- Android Chrome：展開網站「加入手機主畫面」說明；瀏覽器允許時會出現安裝按鈕，或從瀏覽器選單選「安裝應用程式／加到主畫面」。
- iPhone Safari：點 Safari 分享按鈕，選「加入主畫面」，確認名稱後加入。若未直接看到分享按鈕，先開啟頁面選單再選分享；可參閱[Apple官方操作說明](https://support.apple.com/zh-tw/guide/iphone/iph42ab2f3a7/ios)。
- 電腦 Chrome／Edge：依瀏覽器支援，可從網址列或選單的安裝選項加入。若沒有安裝選項，網站仍可正常用於線上查詢。

加入主畫面不會提供即時GPS，也不保證能離線搜尋。安裝提示必須由使用者點擊，不會反覆彈出。

Service Worker只快取通過雜湊驗證的首頁、程式、樣式、Manifest與圖示。**不快取任何CSV、日期表、行政區圖資或資料版本JSON。** 離線時清除畫面上的清運結果，顯示「目前無法更新清運資訊」，仍可匯入／匯出收藏識別；恢復網路後重試取得資料。沒有離線舊資料可展示，因此不會用快取取得時間冒充官方日期。

有新版時顯示「重新載入新版」，由使用者選擇更新。新版必須整組介面資源雜湊通過才可啟用；下載不完整則保留上一版完整介面。啟用後只清理本網站scope的舊介面快取，不清除localStorage收藏與歷史，不影響同網域其他Pages專案。

## 資料來源與日期如何看

結果底部展開「資料來源與更新說明」：

| 欄位 | 本版呈現 |
| --- | --- |
| 官方發布／更新日期 | 官方更新日期未提供 |
| 原始網站資料匯入／更新日期 | 歷史紀錄未完整保存，無法確認 |
| 本站資料版本紀錄 | 這組檔案的雜湊版本與紀錄時間，明列非官方更新日 |
| 本次取得資料時間 | 使用者這次載入作業的完成時間（台灣時間）；重試可能重用同版本的本頁暫存，不代表每份檔案都在此刻重新下載。部分成功時另標示不完整 |

只列出已知真實來源連結，並說明三民西資料集連結不代表全部39檔都有完整下載版本。民眾介面只顯示資源回收日與表定停留資訊，不提供一般垃圾星期篩選；回收日缺值明示「資源回收日尚未提供」。本站提供表定停靠資訊，非即時車輛定位；資源回收日不代表一般垃圾清運星期。歷史243條規則與管理工具仍保留，不新增日期。

檔案雜湊只檢查這組版本是否一致，不代表官方內容已重新核實，也不能證明表定資訊仍然有效。[PWA安裝條件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)及[Worker更新生命週期](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)採標準瀏覽器機制，實際安裝選項依平台而異。

## 維護、產物與測試

```sh
npm ci --ignore-scripts
npm run build:site
npm test
npm run test:browser
npm run audit
npm run audit:locations
npm run reconcile:sanmin-west
```

本機已有Chromium時，可使用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser`。Actions維持既有 `ubuntu-24.04`。

- `js/location-quality.js`：不依賴DOM的座標檢查，網站與報告共用。
- `js/convenience-core.js`：穩定分享識別、備份版本／大小／欄位驗證與原子合併。
- `js/convenience-ui.js`：卡片操作、分享定位、收藏預覽／匯出與日期說明。
- `js/site-data.js`、`data/site-metadata.json`：驗證整組資料版本；重試版本變更時清除本頁舊暫存。
- `manifest.webmanifest`、`icons/`、`js/pwa.js`、`sw.js`：主畫面、安裝指引與介面快取。
- `scripts/build-site.cjs`：依介面內容及Worker模板生成獨立版本；修改前端或資料後須重新執行並提交產物。測試只檢查產物是否過期，不自動改寫它們。
- `scripts/location-report.cjs`：重現全部13,871筆位置判定，不改原始座標。

一般瀏覽器回歸測試封鎖Service Worker以便控制模擬資料；`test/pwa.spec.cjs`另用真實Worker及專案子目錄的測試伺服器，驗證安裝路徑、離線重開、資料不快取、更新切換、壞版本拒絕及原收藏保留。測試伺服器只在本機／CI執行，不是網站後端。

初次讀取包含完整CSV、雜湊與位置檢查，單檔有12秒逾時，因此測試的初始載入就緒等待採15秒；未放寬任何數量、日期、唯一識別或來源一致性斷言。

手機測試為Chromium觸控模擬320／390px、平板768px，不宣稱已在實體手機或原生App完成測試。正式Pages在PR合併前仍是舊版；新增資源已以相同專案子目錄做部署路徑驗證。
