# 附近停靠站、今日回收時間軸與官方動態入口（PR #11）

以已合併PR #10的main（`99665ec`）為基礎，保留綠色、暖白色與既有卡片。本站依然提供**表定停靠資訊，不是垃圾車即時GPS追蹤系統**。三項功能不修改原CSV、日期規則或座標品質政策。

## 找我附近的停靠站

1. 首次載入完成後，在搜尋區按「找我附近的停靠站」。網站載入不會要求定位；只有此按鈕會呼叫定位。
2. 瀏覽器詢問時自行選擇是否允許。允許後，顯示通過既有導航品質檢查的站點，依直線距離由近到遠排列；每批30筆，可「顯示更多」。
3. 搜尋範圍預設1公里，可選500公尺、1公里、3公里、5公里。切換範圍只在本頁重新計算，不再次要求定位，也不重新下載或解析CSV。
4. 卡片保留行政區、村里、正式地點、表定時間、資源回收日、收藏、分享、導航、複製及回報；新增「距離約…（直線距離）」。這是**使用者與固定停靠站的估算距離，不是垃圾車與你的距離，也不是步行或開車路程**。
5. 再按一次按鈕才重新定位。按「搜尋結果」、搜尋、收藏或開啟分享站點，會退出附近模式並清除本次位置；原行政區、村里、關鍵字、星期、時段、排序與收藏保留。附近操作不新增最近搜尋紀錄。

如果沒有結果，畫面會說「目前範圍內沒有通過位置品質檢查的停靠站，可擴大搜尋範圍，或改用地點文字搜尋」，不會說附近沒有垃圾車。

拒絕授權、定位逾時、裝置無法定位或瀏覽器不支援時，顯示繁體中文提示，保留文字搜尋，不會自動重問權限。需要再次嘗試時由使用者主動點擊。

### 與導航共用安全判定

`createConvenienceUI`原有的完整原始資料品質稽核，透過`getLocationAudit()`供附近索引讀取；附近索引僅接受 **`LocationQuality.navigationURL(record)`能產生安全導航網址** 的同一列。沒有第二套較寬鬆的座標判斷。

仍檢查原始數值、軸向、精度、所屬行政區、多邊形／區界距離、識別／地點衝突及可疑共用座標。不補行政區中心、不地理編碼、不交換座標，也不採用Google Maps文字搜尋結果。

沒有路線、日期版本資料或圖資的完整驗證結果時，沿用原導航的保守門檻，**暫停附近搜尋且不要求定位**，提示「附近結果可能不完整，請先重試載入」。不能以缺檔資料推斷跨檔座標沒有衝突。一般文字搜尋仍可使用已載入資料。這項限制保留原安全條件。

### 距離與定位資料

Haversine以平均地球半徑6,371,008.8公尺計算，座標順序與既有報告相同：`[經度, 緯度]`。對三角公式中間值限制於0至1，避免浮點誤差造成NaN；嚴格拒絕非數字、NaN、Infinity與世界範圍外座標。0距離、極點、反向經線及對蹠點有單元測試。

結果以約10公尺的顯示精度呈現；範圍篩選與排序使用原計算值。小於10公尺寫成「約10公尺內」。不代表現地定位有這個精準度，仍須參考畫面標示的定位誤差。

定位只在閉包記憶體保留，**不寫localStorage、IndexedDB或Cookie，不放入分享、收藏JSON、問題回報或網路請求**。沒有`watchPosition`或背景定位。為避免舊定位持續當作目前位置：

- 每次使用`getCurrentPosition`，`maximumAge:0`、裝置逾時10秒，另有12秒頁面截止保護。
- 只接受60秒內的位置，拒絕超過5秒的未來時間戳、無效座標、無效定位誤差或超過1公里的定位誤差。
- 頁面顯示裝置回報的誤差。小範圍搜尋仍可能受此誤差影響，距離僅供參考。
- 最多保留5分鐘；切換畫面、離開頁面、離線或改用其他結果模式會清除。重新整理回一般模式，不能重用前次位置。
- 瀏覽器支援Permissions API變更通知時，撤銷／變更定位權限立即清除並恢復一般模式；不支援該通知時，仍有切換畫面、離頁及5分鐘期限保護。本站無法控制瀏覽器或作業系統本身的定位服務。
- 舊請求晚回傳時以請求序號忽略，不能蓋掉使用者後來的搜尋。重新定位失敗不會繼續展示舊距離。

## 今日資源回收時間軸

1. 先選全高雄市或單一行政區，可輸入地點關鍵字及村里。
2. 在「今日資源回收站點」按「查看今日時間軸」。保留行政區、村里和關鍵字；星期改為台灣今天、清除停留時段並改成由早到晚。沒有使用一般垃圾日期。
3. 畫面顯示台灣日期、星期與目前分鐘。卡片依表定起始／到點時間升冪排序，並沿用收藏、分享、地圖、複製及回報。仍分批30筆，背景時鐘更新不會無故收回已展開的批次。
4. 「全部時段」包含來源明確提供今日回收星期的站點；「表定時間尚未過去」只保留起始／到點分鐘不早於目前台灣分鐘的站點。**當分鐘仍列入，已開始的停留時段不會因結束時間較晚而保留**。這不是車輛位置、到站預測或服務保證。
5. 來源時間空白或無法完整解析時顯示「表定時間尚未提供」，在全部時段排最後，不列入尚未過去。
6. `23:58-00:03`等跨午夜時段保留完整原文並標記跨日歸屬未知。原CSV沒有日期歸屬證據，因此不列入尚未過去；不推測它是昨天延續、今日開始或明日班次。
7. 時間軸中修改關鍵字或村里後，可按「重新套用今日條件」。切換行政區會沿用關鍵字並重新查今日。按「搜尋結果」或普通搜尋按鈕可回一般模式，保留目前合理條件。最近搜尋記錄的是當次星期條件，不是永久「今天」指令。

始終顯示：「以下為表定停靠時間，非即時到站資訊。實際清運可能因交通、天候或臨時調度有所調整。」進階的時間與跨日解釋可展開閱讀。未提供回收星期的站點不會被推算為今日回收。

日期、星期與時分用`Asia/Taipei`，不使用使用者所在時區。每30秒及返回畫面時更新；台灣跨日會重新套用今天的回收星期。沒有倒數、到站預測或以表定時間推算車輛位置。測試也在`America/Los_Angeles`瀏覽器時區驗證台灣跨日。

## 官方垃圾車即時動態入口與查證結果

搜尋區附近提供「查看官方垃圾車即時動態」，前往：

**[高雄市官方清潔車便民查詢系統](https://kepbgps.kcg.gov.tw/)**

入口與本站卡片分開，明確說明本站只提供表定資訊。固定HTTPS網址、無查詢參數或定位資料；使用新分頁及`rel="noopener noreferrer"`。不嵌iframe、不串GPS API、不假設支援站點深層連結，也不在背景連線官方系統。
