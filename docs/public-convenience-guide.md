# 全市搜尋、大字模式、收藏管理與問題回報（PR #10）

以已合併 PR #9 的 `main`（`47822fb`）為基礎，延續綠色與暖白色介面。所有民眾畫面、今日快捷、複製資訊仍只使用資源回收日，不提供一般垃圾星期。

## 全高雄市搜尋示範

1. 在行政區選單最上方選「全高雄市（38區）」。為保留原本操作習慣，初次開啟仍預選前鎮區；全市模式不需選村里。
2. 輸入「中山」，按「搜尋垃圾車」。本版資料共有354張符合卡片，來自16區；首次只顯示30張，按「顯示更多」繼續。行政區與村里始終標在每張卡片上。
3. 展開「星期、時段與排序」，可選資源回收星期、時段、由早到晚／由晚到早。時間是全市一起排序，未提供有效時間的站點排在最後。
4. 地點建議會寫成「行政區｜停靠地點」。選建議時自動切換至該區，輸入框只保留正式地點文字；同地點不同班次仍各自顯示，不會擅自選其中一班。
5. 也可以全市直接搜尋「河北二路102號」，本版會找到三民區的1筆站點；不用先知道行政區。
6. 切換全市／單區保留關鍵字、回收星期、時段與排序，清除村里。按「清除條件」才清空其他條件。最近6組搜尋能保存及恢復全市模式。

部分路線讀取失敗時，會提示「全市部分路線尚未載入，搜尋結果不完整；未找到不代表沒有該地點」，並提供既有重試。重試只下載失敗檔案；全市索引使用既有列的參照，不重複下載CSV。原始13,871筆有效來源列維持不變，只有原本3組完全相同的顯示內容合併成13,868張卡片。

## 大字模式

按頁首「大字模式」即可開啟；顯示「大字模式：開」表示已啟用，再按一次恢復一般模式。切換不重設搜尋或收藏。

文字使用會隨瀏覽器基準字級調整的rem尺寸。正式地點、表定時間、欄位及按鈕都放大，搜尋欄位改單欄、結果改單欄，按鈕可換行，主要觸控操作至少44×44 CSS像素。不用整頁縮放，不限制瀏覽器縮放，也不新增動畫。進階篩選仍可展開使用。

偏好獨立保存在 `garbage-display-v1`：`{"version":1,"largeText":true}`，不覆寫收藏或歷史。若瀏覽器禁止保存，當次仍可切換，但會明示下次可能需重新設定。

## 收藏自訂名稱與置頂

1. 先在站點卡片按「收藏」，再開「我的收藏」。
2. 在收藏卡片按「名稱與置頂」。輸入「家附近」等名稱（最多30個Unicode字元，emoji計一個碼點），並依需要勾選「置頂此站點」。
3. 按「儲存收藏設定」。卡片會標示「自訂名稱」及置頂狀態，**正式地點和表定時間仍保留**。
4. 重新進入同一視窗可修改名稱；清空名稱再儲存即可移除，取消勾選即可取消置頂。
5. 置頂站點在收藏最前方，置頂／未置頂各組內仍依表定時間排序。一般搜尋結果不受影響。
6. 取消收藏時一併刪除該識別的名稱與置頂。資料已變更或尚未載入的收藏仍保留原識別和偏好，絕不改配相似站點。

名稱只在自己的收藏顯示，不會寫入原CSV、一般搜尋、複製停靠資訊或分享網址。所有名稱都是純文字，像 `<b>家附近</b>` 也只會照字顯示，不執行HTML。

### 本機資料與JSON備份

原 `garbage-search-v1` 保持 `version:1`、原 `favorites` 字串陣列及 `recent` 格式；新增可選的 `favoriteDetails:{version:1,entries:{完整識別:{name,pinned}}}` 擴充欄位。舊收藏不用遷移或重新收藏，缺少擴充欄位時採空名稱／未置頂。只有已收藏的識別能保有設定；無效的擴充資料不會刪除原收藏。

匯出按鈕現在下載JSON **version 2**，會一起備份名稱與置頂。例如下面的識別取自既有三民西資料；「家附近」僅為示範自訂名稱：

```json
{
  "format": "kaohsiung-garbage-truck/favorites",
  "version": 2,
  "favorites": [
    {
      "sourceFile": "sanmin-west.csv",
      "district": "三民區",
      "responsibility": "一",
      "trip": "1",
      "place": "河北二路102號",
      "time": "16:19-16:22",
      "name": "家附近",
      "pinned": true
    }
  ]
}
```

換裝置時：開「我的收藏」→匯入JSON→查看新增／重複／合併後總數與未能唯一確認數→確認「合併收藏」。預覽可取消；不提供取代操作。

- 相容舊version 1檔案：每筆只有原本六個識別欄位，新匯入的站點採空名稱／未置頂。
- 重複收藏一律保留本機名稱及置頂，**包括本機空名稱／未置頂**；匯入不會意外覆寫。需要改動時請在收藏自行編輯。
- 檔案內同一識別若有互相衝突的名稱／置頂，整次拒絕，請先檢查備份；完全相同的重複則去重。
- 最大256KiB、每檔最多200筆、合併後最多200個識別。錯誤JSON、版本不支援、缺欄、額外欄位、無效來源、名稱超長或超過容量時，原收藏不變。
- 備份只包含六欄完整識別及個人名稱／置頂，沒有清運日期、經緯度、整份CSV、最近搜尋或大字偏好。請自行保管可能透露個人生活習慣的自訂名稱。
- 瀏覽器無法永久保存時會明確提示，當次操作仍可使用；請立即匯出備份，不要把未保存誤認為已永久保存。

舊的一般垃圾星期搜尋依PR #9規則保留歷史並提示重新選擇，不偷偷改成回收星期。

## 回報問題：只產生文字，不自動送出

每張卡片的次要操作區按「回報問題」：

1. 選地點、表定時間、資源回收日、地圖位置或其他問題。
2. 在「補充說明」輸入最多300個字元，送交前可修改類型和文字；不需要姓名、電話、住址。
3. 展開「查看完整回報文字」可看預覽，自動帶入來源CSV、行政區、責任區、車次、正式地點、完整表定時間、村里、原時間文字、資源回收日及六欄完整識別。
4. 按「複製回報內容」後，自行交給維護者或主管機關。剪貼簿受限時會選取預覽，請長按／手動複製。可按「關閉」或Esc離開，鍵盤焦點回到原卡片。

**這不是線上送件，沒有送出成功或受理承諾。** 未新增或假造收件Email、第三方表單或後端；回報不會寫入正式資料。請避免填寫不必要的個人資料。補充說明中的HTML也一律當作文字。

[390px大字回報視窗](screenshots/report-mobile.png)

回報文字範例（實際站點識別，補充說明僅為示範）：

```text
高雄市垃圾車停靠資訊問題回報（尚未送出）
問題類型：表定時間可能錯誤
來源CSV：sanmin-west.csv
行政區：三民區
責任區：一
車次：1
正式停靠地點：河北二路102號
表定時間（完整識別）：16:19-16:22
村里：建東里
來源表定時間原文：16:19-16:22
資源回收日：一、四
完整站點識別：["sanmin-west.csv","三民區","一","1","河北二路102號","16:19-16:22"]
補充說明：範例：希望協助核對表定時間，尚未送出。
此為表定資訊問題，非即時定位。請勿填入不必要的個人資料。
複製文字不代表已送出、受理或更正資料。
```

所有路徑沿用相對路徑，深層連結的完整識別不變。PWA仍只快取整組通過SHA-256的介面，**不快取CSV、日期表、圖資或資料版本JSON**；離線不展示舊清運日期，可管理收藏備份。安裝及「重新載入新版」流程見[原便利功能教學](convenience-guide.md#加入手機主畫面)。

```sh
npm test
npm run test:browser
npm run audit
npm run reconcile:sanmin-west
npm run audit:locations
node scripts/build-site.cjs --check
git diff --check
```

本機已有Chromium可設 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser`。維持 `ubuntu-24.04` 及 Node.js 22 的Actions設定。
