垃圾車清運日對照表整理工具

自動盤點 39 份 CSV，區分已確認日期與待查證路線

請把本頁 route-organizer.html 上傳到同一個 GitHub 儲存庫，使用 GitHub Pages 開啟後，按下開始整理。

尚未開始。程式不會修改原始 CSV，也不會自動寫入 GitHub。

整理方式

  • 如果原始 CSV 已有「一般垃圾日」及可核對的 HTTPS「官方來源」，會建立停靠站層級的精確對照規則。
  • 保留原本 garbage-days.csv 的有效規則；相同停靠站但日期衝突者不自動輸出。
  • 其餘路線只放進「路線盤點清單」，一般垃圾日留空，等待你核對後填入。

提醒：一般垃圾清運日不等於資源回收日；不能把既有「回收日」直接填入新對照表。相同責任區和車次也可能有不同停靠日期。

輸出檔案用途
garbage-days-generated.csv有來源證據、可供網站使用的規則（下載後檢查，再改名為 garbage-days.csv）
route-inventory.csv每條來源檔案／責任區／車次組合的筆數、樣本停靠站、待核對狀態
